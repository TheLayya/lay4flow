# lay4flow-remote 账号登录扩展

这个扩展恢复原账号导入流程，用于在自己的指纹浏览器中完成 Google / Flow 登录，再把该账号的登录态交给当前 lay4flow-remote 服务验证和保存。

1. 在账号管理的「扩展登录」下载当前站点专用扩展 ZIP，解压后在指纹浏览器的扩展管理页打开开发者模式，加载已解压的扩展目录。
2. 在该指纹浏览器中打开同一个 lay4flow-remote 管理地址并登录管理员账号，刷新页面后进入「扩展登录」。
3. 直接开始登录。Google 登录沿用指纹浏览器已配置的网络与代理，无需在管理页再次选择。扩展在当前浏览器 Profile 新建 Flow 标签页，可复用该 Profile 已有的 Google 登录态；完成 Google / Flow 授权后回到管理页查看验证结果。
4. 登录态提交后，服务端按现有规则分配账号固定出口，使用当前 Flow 接口校验真实账号身份，再保存持久化 Cloak Profile，检查正常关闭与重开后的登录态；后续按其固定代理刷新会话。扩展关闭自己创建的标签页，保留指纹浏览器原有的登录状态。扩展不会读取或修改指纹浏览器的代理配置，服务端也不会自动获得该代理地址。

扩展也兼容 `login_context: "isolated"` 的临时无痕登录流程；此模式需要允许扩展在无痕中运行，并在完成、取消或超时后清理自己创建的临时登录窗口及 Cookie。

扩展只提供账号登录，不参与验证码生成。验证码仍由 `remote_browser` 服务提供。它保留 Google Cookie 的域、路径、HttpOnly、SameSite 和到期时间；Cookie 不写入扩展持久存储或 URL。管理页一次性导入凭据绑定当前管理员，提交只发往当前管理站点。

界面下载的站点专用包会预置精确站点权限，安装后刷新管理页即可连接。更换管理地址或端口后需重新下载并加载专用包。命令行也可构建：

```powershell
python scripts/build_account_import_extension.py --origin http://127.0.0.1:38001 --output account-login.zip
```

扩展 ZIP 仅包含公开源码、清单和 MIT 许可证，不包含账号凭据或本地运行数据。真实 Google 登录成功率与代理质量需在使用环境单独验证。
