# lay4flow-remote 账号登录扩展

当前扩展版本 **1.8.4**。普通 Chrome 或 Microsoft Edge 即可使用，无需指纹浏览器。Windows 桌面入口可直接打开本机浏览器管理页，再把 Google / Flow 登录态交给当前 lay4flow-remote 服务验证和保存。软件内嵌 WebView2 不加载这份扩展，请在桌面弹窗中点击「在本机浏览器中打开」。

直接加载项目中的 `account_import_extension` 文件夹时，本机 `127.0.0.1` 和 `localhost` 管理页会自动连接，包含各端口和 `/#/accounts`、`/login#/accounts` 等管理入口。远程服务器地址需要在该管理页点击浏览器工具栏里的扩展图标，允许访问后再检测；管理页下载的专用 ZIP 已预置对应站点权限。

1. 在账号管理的「扩展登录」下载专用扩展 ZIP，解压后在 `chrome://extensions` 或 `edge://extensions` 开启开发者模式，加载已解压目录。
2. 在扩展详情开启“允许在无痕模式下运行”（Edge：“允许在 InPrivate 中”），回到管理页并刷新。
3. 默认使用临时无痕窗口。先关闭其他无痕窗口，再开始 Google Flow 登录；如果已有无痕窗口，扩展会提示并保留其中的登录态。
4. 提交后登录资料进入后台队列，本次临时窗口结束；服务端验证一次后保存。已有账号更新原 Profile，沿用原固定代理与指纹，失败不自动重试或强制重开。

「扩展未连接」表示当前网页还未收到扩展响应，不是版本检测结果。先检查当前浏览器用户、扩展开关和站点权限，再重新加载扩展、刷新管理页；连接后才会显示并校验版本。后台验证结果在「扩展登录队列」查看；「已排队」不等于账号已验证成功。

也可选择“当前浏览器登录态”，复用普通浏览器或指纹浏览器已有的 Google 登录；此模式保留原会话，只关闭本次新建标签页。登录沿用本机浏览器网络，扩展不读取或修改浏览器代理。

扩展只提供账号登录，不参与验证码生成。验证码仍由 `remote_browser` 服务提供。它保留 Google Cookie 的域、路径、HttpOnly、SameSite 和到期时间；Cookie 不写入扩展持久存储或 URL。管理页一次性导入凭据绑定当前管理员，提交只发往当前管理站点。

界面下载的站点专用包会预置精确站点权限，安装后刷新管理页即可连接。更换管理地址或端口后需重新下载并加载专用包。命令行也可构建：

```powershell
python scripts/build_account_import_extension.py --origin http://127.0.0.1:38001 --output account-login.zip
```

扩展 ZIP 仅包含公开源码、清单和 MIT 许可证，不包含账号凭据或本地运行数据。真实 Google 登录成功率与代理质量需在使用环境单独验证。
