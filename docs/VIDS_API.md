# lay4flow-remote Vids API

Vids 是独立 provider，使用已保存的加密会话。Flow 账号登录成功后仍需通过 Vids 身份、文档和会话校验。默认账号池为空；未接入时不建立媒体会话。

管理界面使用 `/vids-accounts` 管理接入与恢复，`/vids` 提交创作，`/vids-api-guide` 查看完整协议。外部客户端 Base URL 为 `https://your-host.example/providers/vids/v1`，使用本服务 `Authorization: Bearer YOUR_API_KEY`，与管理 Cookie 分开。

| 方法与相对路径 | 用途 |
|---|---|
| `GET /models` | 当前支持的模型与能力 |
| `POST /images/generations` | 文生图与上传原图编辑 |
| `POST /audio/speech` | 语音生成 |
| `POST /videos` | 视频任务 |
| `GET /videos`、`GET /videos/{id}` | 列表与状态 |
| `GET /videos/{id}/content` | 下载完成视频 |
| `GET /vids/generations/{id}` | 原生成收据 |
| `POST /vids/generations/{id}/download` | 恢复原结果下载 |

完整 Swagger 为 `/providers/vids/api-docs`，schema 为 `/providers/vids/openapi.json`。以运行服务提供的字段与能力表为准。

生成必须提供 `Idempotency-Key`。新请求由后台自动选择可用账号，调用方不指定账号；失败换号与收据规则见下文「明确拒绝的有界换号与收据重放」。素材由调用方上传，图片编辑无需客户端选择内部文档或场景 ID。重复同键同请求读取原收据，变更参数返回冲突。

### 语音语言与账号权限

- Vids 语音上游当前仅接受英文输入；中文等其它语言会返回 `400 INVALID_ARGUMENT / LANGUAGE_NOT_SUPPORTED`。这不是本地请求构造错误，客户端应改用受支持的英文文本。该请求型拒绝不属于账号侧可换号类别，后台不会为它更换账号；失败收据保留 `error_operation=generate` 和安全 `upstream_error`。
- `403 PERMISSION_DENIED / CROSS_PRODUCT_SHARING_DISABLED` 表示上游拒绝了该账号的跨产品共享权限；响应码本身无法断定限制来自账号权限还是 Workspace 策略。此类明确拒绝会按下文规则在既有预算内自动尝试其他符合条件账号，但换号不保证恢复，也不能绕过 entitlement。若可用账号均返回该限制，请在账号页维护 Vids 账号授权或补充具备权限的账号，再提交新请求；创作端无需也不能选择账号。
- Vids 账号保护仍沿用现有连续失败阈值、可编辑规则和手动开关；本次换号不改变保护阈值、规则或手动开关，也不新增首次命中自动停用或旁路。图片、视频与语音共用同一生成收据和错误分类路径。

Vids 的只读 HTTP 操作（编辑器初始化、额度、设置、任务状态和媒体下载）使用独立重试预算；`[vids].read_max_attempts` 默认3次，含首次，可设1–5。付费生成、上传和文档写入不会因只读重试而重发；付费生成在账号侧明确拒绝时的有界换号见「明确拒绝的有界换号与收据重放」。视频下载只跟随经过校验的 Google HTTPS 媒体跳转，并保持账号固定代理和 Cookie 作用域。

新请求的账号池会跳过最近15分钟内已确认零额度的对应媒体类型；未知或过期的额度允许重新检查，最终仍以生成前实时校验为准。每份已认领的物理尝试与收据保留原账号；同一新逻辑请求仅在收到账号侧明确拒绝后，才以新的物理收据换到其他账号。显式账号路由、已有收据和引用原账号素材的操作始终保留原账号。15秒视频仍需单独验收。

### 明确拒绝的有界换号与收据重放

- 仅新建立、未绑定账号且尚未受理的付费生成请求，在收到账号侧明确拒绝（HTTP 401/403/429）时可自动改用其他符合条件账号；总次数受既有生成最大尝试预算约束，每个账号至多一次。
- `LANGUAGE_NOT_SUPPORTED` 等其余请求型 4xx、5xx、传输/取消、下载/媒体错误、受理未知或已受理结果不换号补发。后台返回的仍是既有物理收据结构与最终收据 ID，不新增请求字段、账号选择参数或客户端重试循环。
- 每份物理收据保留实际提交账号的归属；同一幂等键的原请求通过确定性的后继链接返回最终物理收据，不产生第二次客户端提交。升级前已处于终态的收据只用于重放读取。Studio 重启后只读跟随已持久化的后继收据，不补发生成。
- 公共 API 与管理端账号池共享同一选择规则；显式账号路由、已有收据和引用原账号素材的操作保持固定账号。

「工坊设置 → 自定义规则 → Vids 会话维护与保护」独立配置后台维护开关、间隔、恢复退避和连续失败保护。维护只处理已有绑定的空闲、启用账号；跳过正在生成、手动停用或受 Vids 保护的账号，失效会话通过原账号、原文档和原固定代理恢复，不重新接入或创建文档。账号详情显示最近检查、成功检查、下次检查及安全错误码。

Vids 规则格式为 `关键字|LIMIT|10m`、`关键字|DEACTIVE` 或 `关键字|DISABLE`，仅影响后续 Vids 新任务。自定义规则本身不重发付费任务，因此不支持 `RETRY` 和 `DELAY`；账号侧明确拒绝的有限换号由账号池按既有生成最大尝试预算自动完成，受理未知或已受理结果不重发。规则清空后不匹配隐含关键词；默认连续3次明确账号相关失败后冷却300秒，可自行修改。网络受理结果未知、下载、上传、参数及探活错误不会默认触发账号失败保护。解除 Vids 保护不会启用手动停用的 Flow 账号。

更新后的 Vids 生成按收据写入请求日志和独立统计；重复同键请求、状态查询和恢复下载不会重复计数。失败/结果未知/待恢复下载分别显示，生成错误不再混入 Flow 的统计与保护状态。已有历史收据不会在更新时补算用量或重新触发保护。

Vids 已完成的本地图片、视频和语音沿用「工坊设置 → 媒体缓存 → 缓存保留时间」；0 表示持续保留。Flow 媒体链接缓存开关只控制 Flow 的链接缓存，Vids 下载接口仍需本地成品，因此保留时间可单独修改。后台仅回收超过期限的已完成媒体，正在下载、生成、受理未知或下载失败的任务会跳过；加密会话、账号绑定和幂等收据保留。过期媒体下载返回410，收据仍为已完成，同键请求不会重新生成。显式恢复下载只尝试取回原响应中的文件，上游原文件失效时返回错误，不消耗新的生成额度。

Flow 与 Vids 复用同一份账号浏览器 Profile。成功关闭后清理可再生缓存；后台另对异常关闭遗留的空闲 Profile 执行回收，检查账号锁、进程、身份和目录归属，不确定浏览器是否退出时跳过。Cookie、站点存储、指纹和固定代理资料不会被清理。

已启用、具备图片或视频能力的就绪 Cloak Profile，在 Flow 导入或会话刷新后可触发一次后台接入，按需创建空白 Vids 文档；失败状态会保存，后续可在账号页显式重试。管理员也可手动接入，选择是否创建空白文档。身份不一致、Profile 验证未通过或会话失效时停止并显示原因。恢复使用原账号与原文档，不重放付费生成。图片、视频和语音的支持范围由 `/models` 描述，音乐不在当前范围内。

`[vids].accounts` 保留已配置绑定，界面接入的账号默认写入 `data/vids/bindings.json`。会话加密保存，解密密钥由绑定的 `session_key_env` 环境变量或独立的 `session_key_file` 文件提供；界面接入默认将密钥放在 `data/vids-secrets/`。跨服务器移动时同时保留原绑定、密文与独立保管的解密密钥；自定义到 `data/` 外的路径也需备份。私有配置、密钥、Cookie、原始收据均排除于 Git 和发布包。

本项目的远程有头验证码配置属于 Flow 生成链，Vids 会话与原有 provider 协议分别管理。离线回归使用合成会话；真实 Vids 付费生成及具体参数组合需在部署环境单独验收。
