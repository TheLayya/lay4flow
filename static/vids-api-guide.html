Vids / 开发者 HTTP API

Vids 媒体 API

将 Vids 反代为 API。图生图上传原图、填写提示词，一次请求返回成品或原生成收据；无需读取可编辑图片、场景或文档内部 ID。控制台使用同一 API，管理登录 Cookie 通过 /api/admin/vids/v1 使用后台账号池，无需输入 API Key、Token ID 或选择账号。账号管理负责接入、身份、会话与额度。下文开发者示例使用 /providers/vids/v1 与共享 Bearer key；文档页面本身不发请求或读取 Cookie。

源码能力：当前候选真实图生图：待验生产发布：待验音乐：排除
Flow 账号需要通过 Vids 身份和会话验证才进入可用池。后台为新幂等键选择已启用且可用的账号，原图准备与生成收据固定原账号，unknown 不换号、不补发。管理接口不进入公开 provider Swagger。

能力与验收范围

图片文生支持 1–4 张、三种比例与七种风格，图生图输出尺寸由上游返回；视频接入 3–10 秒、横竖屏 720p/1080p、文生、动画、参考图、编辑、续写与放大。支持参数与真实实测记录分别列出；语音支持30个预设，Puck、Gacrux、Algenib 已真实验收短英文 WAV；其余27个尚未逐一实测。新的真实付费图生图尚未验收；真实多账号生成、跨天会话寿命和生产部署仍待验。

仅管理控制台

账号自动接入与会话恢复

新导入的 Flow 账号或其 Profile 成功验证后，后台自动尝试 Vids 接入：复用该账号已经登录的 Profile，核对 Google/Vids 身份，优先使用已有文档，没有文档时创建空白 Vids 文档，再保存加密会话与绑定。接入不上传素材、不提交生成。需要登录、验证码或 Profile 环境验证时停止，并提示管理员处理；身份不匹配不会进入可用池。现有未绑定账号可在账号管理点击“一键接入未绑定账号”，逐个接入并查看结果。

以下接口使用管理员登录 Cookie，不接受共享 Bearer key，不进入公开 provider Swagger。管理响应不返回 Cookie、会话密钥、编辑文档地址或私有文件路径；本页仅说明接口，不执行请求。

方法完整路径行为
GET/api/admin/vids/accounts已绑定账号的本地安全摘要。
GET/api/admin/vids/accounts/detail配置/连接数、已验证身份、会话与上次额度缓存；不查询上游额度或打开 Profile。
GET/api/admin/vids/status生成可用数与缓存额度汇总；不触发接入或生成。
GET/api/admin/vids/onboard/candidates未绑定账号候选；不启动 Profile。
POST/api/admin/vids/onboard/{token_id}JSON 只接受布尔 create_blank，默认 false。一键接入发送 {"create_blank":true}，允许在没有文档时创建空白文档。
POST/api/admin/vids/onboard/{token_id}/reconnect无需请求体；只恢复同身份、原编辑文档，不新建文档、不重放生成。
POST/api/admin/vids/accounts/{token_id}/quota-refresh无需请求体；串行查询图片、视频额度。会话不可用或上游 401/403 时可先恢复一次同账号会话，再重试只读额度查询。

启动优先恢复已保存的加密会话，认证失效时可用原账号 Profile 修复。接入、恢复会话和额度查询中的会话修复可能打开 Profile。新生成在付费提交前先对已选账号做只读会话/额度预检；认证失效时最多修复一次同账号会话，检查通过后才提交生成。媒体提交继续纯 HTTP，修复不会重试已提交的付费生成。历史收据重放直接读取原收据，不做该预检。查询失败时保留上次余额并标记过期与错误；“关联 Flow”邮箱不代表“已验证 Vids 身份”，缓存余额不代表当前会话可用。

产品控制台

模式、比例与素材

控制台从 /api/admin/vids/v1/models 的 capabilities 读取模式及参数。图片文生支持 aspect_ratio=1:1/16:9/9:16 与 style=auto/photography/background/vector/sketch/watercolor/cyberpunk，均为原生生成参数。auto / 1024x1024 保留尺寸校验，url / b64_json 选择响应格式。图生图输出尺寸由上游返回，显式比例和风格会被拒绝。图生图选择本地原图、填写提示词、点击生成，一次请求发送 kind=image、mode=edit、prompt 与 image_base64；后台自动准备原图，无需用户先读取或选择场景、单独保存图片。

视频模式素材支持参数
text提示词3–10 秒；横竖屏 720p/1080p
animate单张 image_base643–10 秒；横竖屏 720p/1080p
ingredients1–7 张有序 images_base643–10 秒；横竖屏 720p/1080p
edit上传 MP4；可选 1–3 张参考图输出 3–10 秒；横竖屏 720p/1080p
extend上传 MP4追加 3–10 秒；成品为 min(源时长,10) 加追加时长；默认源方向 720p
upscale上传 3–10 秒 MP4保持源时长与方向，输出 1080p

视频 size=1280x720/720x1280/1920x1080/1080x1920；shot_mode=auto/long_take/montage 为默认、长镜头或蒙太奇；仅 text/ingredients/edit 接受非 auto。supported_specifications 是实现支持范围，完整矩阵尚未逐项真实付费实测。

视频编辑、续写、放大都只接收用户上传 MP4，最多 50 MiB；edit/extend 输入 3–60 秒、使用末 10 秒，upscale 输入 3–10 秒、保持原时长/方向。无需先读取已完成的视频，视频 source_id 新请求拒绝。上传续写/放大仅合成协议验收，尚未新增真实付费实测。素材图支持 PNG/JPEG/WebP，纯 Base64 不带 data URL；全部解码总量最多 10 MiB。语音输入最多 4096 字符，提供30个官方预设声线 / wav。超出支持范围的参数会被拒绝。

Google 产品说明确认 3–10 秒、横竖屏、720p/1080p、Create 最多 7 图和 Edit 最多 3 图：Vids 视频帮助。2026-09-23 官方更新确认 Gemini Omni 1.1 Flash、1080p 生成/放大和续写；产品说明不替代本项目的真实验收。

请求约定

认证与幂等

公共基址与请求头

基址为 https://your-lay4flow-host/providers/vids/v1；调用方不传账号 ID。使用现有共享 API key，而非 Google Cookie、加密会话密钥或管理员会话。常规图片/语音 JSON 最多 1 MiB，通用生成和标准视频 JSON 最多 85 MiB；图片编辑 multipart 整体最多 11 MiB，原图最多 10 MiB；视频 multipart 最多 61 MiB，MP4 最多 50 MiB，图片总量最多 10 MiB；标准视频 JSON 可携带 Base64 素材。

Header要求说明
Authorization所有端点必填Bearer YOUR_API_KEY；模型、状态与文件下载也需认证，不支持查询字符串 key。
Idempotency-Key所有创建必填1–200 个字符。相同 key 与规范参数重放原收据；同键改参数或更换原图返回 409。
Content-Type按请求文生图使用 application/json；图生图使用 multipart/form-data；视频也接受携带图片或 MP4 文件的 multipart。

收据归属于首次使用它的账号；换账号复用同一 key 返回 409 account_affinity_conflict。要继续识别旧 key，必须保留原账号绑定、原 runtime 目录和会话加密密钥；移除原绑定或收据会破坏归属扫描，不可据此换号重发。

账号 disabled 后，已有收据查询、同键重放与已下载成品仍可用；已接受结果的恢复下载也可在会话正常时执行。新生成会被共享数据库的启用状态拦截。未绑定账号返回 404 account_not_found；身份或 runtime 不匹配返回 409。

超时或 unknown 不重发。 网络中断后先用原账号、原 key 和原参数读取原收据。unknown 表示上传或生成接受状态不明；付费生成可能已消费，不能换 key 重做。同键仅重放原收据，不会自动继续上传或付费。查询只读本地收据，不保证从上游查回丢失响应；下载恢复只使用已保存的接受响应。

统一入口

通用生成收据

POST/providers/vids/v1/vids/generations

此入口接受 Vids 字段并返回持久收据，单次请求同步等待媒体生成；没有新增后台任务队列。图片、语音和视频的兼容入口见下面各节；同一幂等键规则适用于两者。返回 202 表示 generating/received/unknown，其余状态返回 200，仍需检查 status。

字段类型 / 必填说明
kindstring / 是image、speech 或 video；音乐被账号分派层拒绝。
promptstring / 是1–32000 字符且不能全空白；语音也使用此字段。
modestring / 否视频、图片默认为 text；高级模式见末节。
secondsinteger / 否text/animate/ingredients/extend 默认 3；edit 默认源时长四舍五入后最多 10，upscale 沿用源时长；通用入口必须是整数。
sizestring / 否text/animate/ingredients 默认 1280x720；edit/extend 默认源方向 720p；upscale 为源方向 1080p。
ninteger / 图片 text1–4，默认 1；同一上游请求返回全部图片；edit 保持单成品
aspect_ratiostring / 图片 text1:1（默认）、16:9、9:16；edit 显式拒绝
stylestring / 图片 textauto（默认）、photography/background/vector/sketch/watercolor/cyberpunk；edit 显式拒绝
shot_modestring / 视频auto（默认）、long_take、montage；仅 text/ingredients/edit 接受非 auto
image_base64string / 图片 edit 或视频 animate单张纯 Base64 PNG/JPEG/WebP
images_base64array[string] / 视频ingredients 1–7 张，edit 可选 1–3 张
video_base64string / 视频 edit/extend/upscale用户上传纯 Base64 MP4，最多 50 MiB；edit/extend 3–60 秒，upscale 3–10 秒
voicestring / 否语音默认 Puck；通用入口可校验源码预设清单，短英文 WAV 已真实验收 Puck、Gacrux、Algenib，其余27个声线尚未逐一实测。

图片

图片生成

POST/providers/vids/v1/images/generations
字段类型 / 必填允许值
modelstring / 是vids-image
promptstring / 是1–32000 字符，不能全空白
ninteger / 否1 / 2 / 3 / 4，默认 1；布尔值或字符串会被拒绝

文生图 n=1–4 使用原生数量字段，一次生成返回按上游顺序排列的全部 data。每张图片分别核验，数量或任一成品不符时不宣称部分成功。多成品收据新增 outputs（index/metadata/content_url）；首图沿用旧地址，其余内容使用 ?index=1/2/3，全部仍需原账号鉴权。同键改变 n 返回 409；省略 n 与 n=1 兼容。恢复下载只读取原接受响应，不再次生成。实际配额扣减方式尚未新增付费核验。

generating/received/unknown 返回 409 image_not_ready；其他非完成状态返回 502 image_failed。读取错误中的收据地址继续恢复。URL 下载仍需携带 Bearer key；没有匿名公开图片地址。

图片 / 原图编辑

图生图 API

POST/providers/vids/v1/images/edits

上传原图和提示词，一次请求返回编辑成品或原生成收据。客户端无需读取可编辑图片、场景或文档内部 ID。独立网关使用 /v1/images/edits；管理同名入口 /api/admin/vids/v1/images/edits 使用管理员 Cookie 自动选账号。

字段类型 / 必填规则
modelstring / 是vids-image
promptstring / 是非空白，1–32000 字符
image / image[]file / 是恰好一张 PNG/JPEG/WebP，最多 10 MiB；两个字段不能同时提交。
nstring / 否只能 1，默认 1
sizestring / 否auto 或 1024x1024，默认 auto
response_formatstring / 否url 或 b64_json，默认 url

使用 multipart/form-data，请求体最多 11 MiB，单个文本 part 最多 128 KiB。未知字段、重复文本字段、多文件及非图片内容拒绝。让客户端自动设置 multipart boundary；不用手动添加 Content-Type。

图生图 size=auto 返回上游实际成品尺寸，不保证方图。显式 aspect_ratio、style 和比例 size 被拒绝；编辑协议没有这些强制输出参数。1024x1024 仅作下载后的成品校验，不能保证上游输出该尺寸；实际不符返回 502 image_specification_mismatch，不得自动重新生成。

请求 · cURL
curl https://your-lay4flow-host/providers/vids/v1/images/edits \
  -H 'Authorization: Bearer YOUR_API_KEY' \
  -H 'Idempotency-Key: image-edit-001' \
  -F model=vids-image -F 'prompt=Make the scene nighttime' \
  -F 'image=@input.png;type=image/png' \
  -F n=1 -F size=auto -F response_format=url
Python · 上传原图并下载成品
import requests
headers = {"Authorization": "Bearer YOUR_API_KEY"}
with open("input.png", "rb") as original:
    r = requests.post(
        "https://your-lay4flow-host/providers/vids/v1/images/edits",
        headers={**headers, "Idempotency-Key": "image-edit-001"},
        data={"model": "vids-image", "prompt": "Make the scene nighttime",
              "n": "1", "size": "auto", "response_format": "url"},
        files={"image": ("input.png", original, "image/png")}, timeout=180)
r.raise_for_status()
edited = requests.get(r.json()["data"][0]["url"], headers=headers, timeout=30)
edited.raise_for_status()
with open("edited.jpg", "wb") as output:
    output.write(edited.content)
200 OK · 与文生图相同的响应
{"created":1780000000,"data":[{"url":"https://your-lay4flow-host/providers/vids/v1/vids/generations/vids_EXAMPLE/content"}]}

HTTP / code含义与动作

开发者高级能力

模式与素材

图片编辑直接调用标准 multipart 原图编辑 API，或通用生成入口的 image_base64。自动账号池通用入口也支持模式与规格表中的视频组合，使用 image_base64/images_base64 与用户上传的 video_base64。历史图片 shape_id 和管理前缀的图片 source_id 仅保留既有调用兼容，与新原图字段不能混用。标准 /videos 与通用入口复用全部视频模式和校验，JSON 使用 Base64，multipart 使用图片或 MP4 文件。文档发现与插入的历史诊断接口无需出现在客户端图生图流程中。

完整字段说明见源码 checkout 中的 docs/VIDS_API.md。本页不触发任何请求、不读取密钥，也不展示音乐端点。

尚未接通的功能

文生图 n>1 多成品已接通（1–4 张），协议与合成验收通过，尚未新增真实付费验收。当前仍不能称为 Vids 全功能 API：Avatar（含个人头像/声音）、首尾帧控制、模型切换尚未接通。MP4 上传编辑10秒720p已通过中文/英文真实成品及鉴权下载验收；其余组合、上传续写/放大未逐项实测，地区/账号是否允许上传编辑以上游结果为准。图片 edit 不支持强制输出比例/风格；图片任意像素分辨率、视频 1:1/4K 没有 Vids 协议证据。没有静默裁剪、换模型或换渠道补齐。

文档图片与场景

反代图生图直接使用原图编辑 API，无需调用以下接口。四项旧接口保留兼容，使用管理员登录 Cookie，仅挂在 /api/admin/vids/v1；不属于自动账号池 provider API，也不进入其 Swagger。图片和场景返回不透明引用与显示名称，隐藏账号及文档内部 ID。旧图片 source_id 为 vids_image_ 加 64 位十六进制，沿用原账号归属。

方法完整路径行为
GET/api/admin/vids/v1/vids/document/images读取已保存图片，返回 source_id / label。
GET/api/admin/vids/v1/vids/document/scenes读取可保存场景，返回 scene_id / label；引用为 vids_scene_ 加 64 位十六进制。
POST/api/admin/vids/v1/vids/document/imagesJSON image_base64 / scene_id 加 Idempotency-Key，上传并插入所选已保存场景。完成后返回编辑用 source_id。
POST/api/admin/vids/v1/vids/document/images/{identifier}/verify按插入收据 ID 读取文档核验；无需请求体，不重新上传。

原图编辑 API 由后台自动读取可保存场景、选择首个场景、上传并确认原图，再提交编辑生成。客户端只提交原图与提示词。上传确认不明或付费生成 unknown 时，后台停止并保留原生成收据，不再次上传，也不提交付费生成。旧插入收据的 verify 只检查原保存，不重新上传；这些诊断接口不属于测试页主流程。
