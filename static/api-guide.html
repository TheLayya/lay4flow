商务对接 / 渠道接入

渠道接入

选择适合的调用路径，地址、SKU 与计费规则一起配置。

普通 OpenAI 渠道Chat / Images 使用现有网关接口。
每个 SKU 独立价格模型名称锁定规格，下游设置零售价。
Videos 原生任务创建、查询、下载、删除和编辑接口均已实现。

基本配置

参数名类型必填说明 / 默认值
Base URLURL是普通渠道填 https://your-lay4flow-host/compat；不加 /v1。
API KeyBearer是管理后台 API Key；请求头 Authorization: Bearer YOUR_API_KEY。
SDK base_urlURL是https://your-lay4flow-host/compat/v1。
模型与价格SKU / 倍率是直接配置真实 SKU，不映射回聚合模型。

网关支持范围

路径New API原版 One API
Chat 图片/视频/编辑普通 OpenAI 渠道，按次或倍率普通 OpenAI 渠道，固定用量倍率
Images 生成支持，按张配置支持，按模型倍率
Images 编辑有对应路由，按实际版本验证 multipart 转发不支持，改用 Chat 参考图
Videos 异步任务本服务已适配；网关须有支持这些 SKU 的任务适配，不能仅以有 Sora 插件推断支持不支持原生 Videos；使用 Chat 视频

鉴权与端点

所有生成、查询、下载、删除均要求 Bearer Key；不接收 Google Cookie。Swagger 和 OpenAPI 文档链接随模式切换，文档页面不读取 Key、不提交生成任务。

商务对接 / SKU 参数与素材

SKU 参数与素材

锁定收费规格与普通参数分别校验；冲突在提交上游前返回 400。

规格规则

参数名类型必填说明 / 默认值
图片清晰度SKU是模型 + 1K/2K/4K；Lite/Imagen 仅1K。
视频生成规格SKU是模型 + quality + seconds + resolution；Relaxed 另加 -relaxed，默认 standard 省略；Veo8秒，Omni4/6/8/10秒。
Omni编辑SKU是flow-omni-1-1-flash-edit-{360p|720p|1080p|4k}；无固定秒数，按次结算。
aspectRatiostring否图片16:9/9:16/1:1/4:3/3:4（Imagen仅前两项），视频16:9/9:16。
modestring否text_to_video/image_to_video/first_last_frame/reference_to_video；编辑SKU仅edit。
trimStartMs/trimEndMsinteger ms否编辑片段：0 ≤ start < end，片段≤10000毫秒且不超过源视频。
图片size/qualitystring否像素size是比例提示，quality=auto/standard/high/hd不改变SKU清晰度。

素材数量与限制

用途素材限制
图片生成/编辑0–10图PNG/JPEG/WebP；编辑上传每张20MiB，总100MiB。
首帧/首尾帧1图/2图首尾帧明确mode，按图片顺序。
参考视频Veo最多3图、Omni最多7图允许模式以SKU为准；两图不自动当首尾帧。
视频编辑1视频，可附最多5图仅Omni编辑SKU；上传视频100MiB，所有上传合计100MiB。

Typed 单图默认首帧，多图默认参考模式；Markdown 引用请显式传mode。URL素材下载会检查公网地址、类型和大小，不支持 file_id、mask 或任意本机路径。

商务对接 / Chat SSE 与用量

Chat SSE 与用量

stream=true 等待完整成品后再发送，不提供实时生成进度。

POST/compat/v1/chat/completions

请求参数

参数名类型必填说明 / 默认值
modelstring是完整 SKU 模型名，锁定收费规格。
messagesarray是最后一条消息为提示词；content 可为文本或包含 text/image_url/video_url 的数组。
streamboolean否默认 false；true 时等待成品后返回 SSE。
ninteger否只能 1。
generationConfigobject否imageConfig/videoConfig，允许比例/生成模式；编辑允许裁剪，锁定规格不能覆盖。
stream_options.include_usageboolean否兼容标准字段；商务 SSE 总会包含最终结算用量。

请求示例

{
  "model": "flow-banana-pro-4k",
  "messages": [
    {
      "role": "user",
      "content": "窗边的一只猫"
    }
  ],
  "stream": true,
  "stream_options": {
    "include_usage": true
  }
}

响应示例

200 OK · JSON
data: {"id": "chatcmpl_example", "object": "chat.completion.chunk", "created": 1780000000, "model": "flow-banana-pro-4k", "choices": [{"index": 0, "delta": {"role": "assistant", "content": "![Generated Image](https://your-lay4flow-host/tmp/example.png)"}, "finish_reason": null}]}

data: {"id": "chatcmpl_example", "object": "chat.completion.chunk", "created": 1780000000, "model": "flow-banana-pro-4k", "choices": [{"index": 0, "delta": {}, "finish_reason": "stop"}]}

data: {"id": "chatcmpl_example", "object": "chat.completion.chunk", "created": 1780000000, "model": "flow-banana-pro-4k", "choices": [], "usage": {"prompt_tokens": 1000, "completion_tokens": 0, "total_tokens": 1000}}

data: [DONE]

Content-Type: text/event-stream；终末choices=[]携带usage，再发送[DONE]。请求HTTP失败时响应仍为JSON错误，不先发送200。普通示例中的Python JSON读取器不解析SSE；下面Python流式示例直接打印事件行。

Python · 读取 SSE
import httpx
body = {"model":"flow-banana-pro-4k","messages":[{"role":"user","content":"窗边的一只猫"}],"stream":True}
with httpx.stream("POST", "https://your-lay4flow-host/compat/v1/chat/completions", headers={"Authorization":"Bearer YOUR_API_KEY"}, json=body, timeout=2400) as response:
    response.raise_for_status()
    for line in response.iter_lines():
        if line.startswith("data:"):
            print(line)

Omni 视频编辑

复用Videos创建路由，编辑SKU固定分辨率，成片时长来自所选源片段。

POST/compat/v1/videos

请求参数

参数名类型必填说明 / 默认值
modelstring是flow-omni-1-1-flash-edit-{360p|720p|1080p|4k}。
promptstring是编辑指令。
input_videomultipart file是上传源视频≤100MiB；不是任意视频URL或任务ID。
input_reference[]repeated files否最多5张参考图，单张20MiB，所有上传合计100MiB。
generationConfigJSON string否videoConfig trimStartMs/trimEndMs（毫秒），片段≤10秒且不超过源视频。
seconds / durationSeconds—不接受编辑时长由源片段决定。
Idempotency-Keyheader string否重复请求保护，同创建接口。

请求示例

{
  "model": "flow-omni-1-1-flash-edit-720p",
  "prompt": "把画面中的猫换成兔子",
  "input_video": "@source.mp4",
  "generationConfig": {
    "videoConfig": {
      "trimStartMs": 0,
      "trimEndMs": 8000,
      "aspectRatio": "16:9"
    }
  }
}

响应示例

200 OK · JSON
{
  "id": "video_example",
  "object": "video",
  "created_at": 1780000000,
  "status": "queued",
  "progress": 0,
  "model": "flow-omni-1-1-flash-edit-720p",
  "prompt": "把画面中的猫换成兔子",
  "seconds": "8",
  "size": "1280x720",
  "completed_at": null,
  "error": null,
  "expires_at": null
}

响应为queued任务，后续使用同一查询/下载/删除接口。默认编辑0–10秒；短于10秒的MP4请显式设置trimEndMs。输入视频处理、编辑和放大都失败时任务标记failed。当前不提供 /videos/{id}/remix；Veo续写仍通过聚合API，不能冒充编辑。

普通网关同步编辑

{
  "model": "flow-omni-1-1-flash-edit-720p",
  "messages": [
    {
      "role": "user",
      "content": [
        {
          "type": "text",
          "text": "把猫换成兔子"
        },
        {
          "type": "video_url",
          "video_url": {
            "url": "data:video/mp4;base64,SOURCE_VIDEO_BASE64"
          }
        }
      ]
    }
  ],
  "generationConfig": {
    "videoConfig": {
      "trimStartMs": 0,
      "trimEndMs": 8000
    }
  }
}

Chat 编辑完成后返回视频链接和一次1000结算单位，适合不支持原生Videos的下游。

商务对接 / 独立定价与结算

独立定价与结算

下游管理零售价，我们提供锁定规格、成功事实和固定结算单位。

Chat 固定单位

200 OK · JSON
{
  "usage": {
    "prompt_tokens": 1000,
    "completion_tokens": 0,
    "total_tokens": 1000
  }
}

1000是一次合格媒体成品的兼容结算单位，不是Google实际token，不是金额。同SKU不随提示词或媒体链接长度变化。Omni编辑按次，一个片段最多10秒。

网关价格设置

参数名类型必填说明 / 默认值
New APImodel price是每个SKU设置固定按次价/固定表达式，或输入用量倍率。
One APImodel ratio是Chat最终ceil(1000×模型倍率×分组倍率)。
Imagesper image是每次n=1，遵循网关按张规则，单独验证。
Videosasync task适配后创建/轮询/下载/删除不返回usage；任务计费由网关按完成/失败状态结算。

倍率示例

若下游500000 quota=1 USD、分组倍率1，要收0.10 USD/次，One API输入倍率设50。实际换算由下游额度配置决定。长提示词/max_tokens可能影响旧网关预扣门槛，建议不填写max_tokens。

已验证范围

One API v0.6.10 / New API rc.43官方容器的4个图片/视频SKU、普通/流式/图片不同定价和HTTP失败零消费已用合成生成对账；不等于所有版本或原生异步Videos网关适配已通过。

商务对接 / 错误与边界

错误与边界

错误不会伪装成高规格成功；网络故障的退款取决于下游实现。

状态码

参数名类型必填说明 / 默认值
400invalid_request—SKU不存在、锁定规格冲突、素材/trim不合法。
401invalid_api_key—Bearer认证失败。
404not_found—模型/任务不存在或不属于此Key。
409video_not_ready / video_in_progress / idempotency_conflict—任务状态或幂等请求冲突。
410asset_expired—缓存文件已过期。
413 / 415request_too_large / invalid_request—大小或Content-Type不支持。
502upscale_failed / output_size_mismatch / output_duration_mismatch—放大或交付规格检查失败。
503video_unavailable / no capacity—任务服务不可用或没有可用账号。

错误响应示例

400 · JSON
{
  "error": {
    "message": "Requested parameters conflict with SKU resolution",
    "type": "invalid_request_error",
    "code": "invalid_request",
    "param": "resolution"
  }
}

等待、重试和能力限制

Chat/Images同步等待，视频可能数分钟；stream=true也不提前推生成进度。Videos有Idempotency-Key，其它创建接口没有同等跨请求幂等，超时后不盲目重试。客户端断线、网络故障、代理超时由网关决定退款，不能保证所有情况自动退费。

本服务适配原生Video并不使旧网关新增路由：原版One API不支持异步Videos；New API需匹配SKU/协议的任务适配。所有成品链接与下载受缓存期限影响，请及时保存。

生成视频

Videos：可恢复的异步视频任务。返回任务 ID，不直接返回视频。

POST/v1/videos

JSON 或 multipart/form-data · Authorization: Bearer YOUR_API_KEY

创建任务 → 查询状态 → 下载 MP4

请求参数

参数名类型必填说明 / 默认值
promptstring是视频描述，1–32000 字符
modelstring否veo_3_1（默认）或 omni_1.1_flash

视频接口 / 查询任务

查询视频任务

创建成功不代表生成完成。约每 5 秒查询一次，直到 completed 或 failed。

GET/v1/videos/{video_id}

请求参数

参数名类型必填说明 / 默认值
video_id路径 string是创建响应的 id；把示例 video_example 换成实际值

请求示例

curl 'https://your-lay4flow-host/v1/videos/video_example' -H 'Authorization: Bearer YOUR_API_KEY'

响应与状态

返回与创建相同的完整任务对象。下面仅展示完成时的关键字段。

200 OK · 关键字段
{
  "id": "video_example",
  "status": "completed",
  "progress": 100,
  "completed_at": 1791504100,
  "error": null
}
status含义下一步
queued排队中5 秒后再查询
in_progress生成中5 秒后再查询
completed完成下载视频
failed失败读取 error，停止轮询

列表与删除

接口参数 / 返回
GET /v1/videoslimit 默认 20、范围 1–100；order 为 asc / desc；after 填上一页 last_id。返回 data、has_more、first_id、last_id。
DELETE /v1/videos/{video_id}仅删除终态任务；运行中返回 409 / video_in_progress。成功返回 {"id":"…","object":"video.deleted","deleted":true}。

查询、列表、下载与删除都需要创建时的同一 API Key。

          "type": "image_url",
          "image_url": {
            "url": "data:image/png;base64,LAST_FRAME_BASE64"
          }
        }
      ]
    }
  ],
  "generationConfig": {
    "videoConfig": {
      "mode": "first_last_frame",
      "durationSeconds": 8,
      "resolution": "720p",
      "quality": "fast"
    }
  }
}

占位 Base64 换成真实图片编码，也可填可下载 URL。参考图模式改成 reference_to_video，素材数量见模型参数。

{
  "choices": [
    {
      "message": {
        "role": "assistant",

读取 choices[0].message.content 或 media.url。视频 content 为视频 HTML，不是 Images 的 data[].url。SSE 读取 choices[0].delta，最终块可能带 delta.media；遇到 error 需处理，流以 data: [DONE] 结束。

兼容接口 / Gemini

Gemini 原生格式

model 写在路径中；请求体用 contents / parts，不用 messages。

POST/v1beta/models/{model}:generateContent

请求参数

参数名类型必填说明 / 默认值
model路径 string是公开模型调用名
contentsarray是parts 放 text、inlineData 或 fileData
generationConfigobject否查看图片 / 视频参数

认证可用 Bearer、x-goog-api-key 或 ?key=。建议请求头，避免密钥进入 URL 日志。也支持 /models/{model}:generateContent。

请求示例

{
  "contents": [
    {
      "role": "user",
      "parts": [
        {
          "text": "一只橘猫"
        }
      ]
    }
  ],
  "generationConfig": {
    "imageConfig": {
      "aspectRatio": "1:1",
      "imageSize": "1k"
    }
  }
}

参考图 part：{"inlineData":{"mimeType":"image/png","data":"BASE64_IMAGE"}}。data 为纯 Base64，不加 data:image 前缀。

响应示例

200 OK · 文件引用示例
{
  "candidates": [
    {
      "content": {
        "role": "model",
        "parts": [
          {
            "fileData": {
              "mimeType": "image/jpeg",
              "fileUri": "https://your-lay4flow-host/tmp/image.jpg"

读 candidates[0].content.parts；图片可能为 inlineData 或 fileData。流式使用 :streamGenerateContent，按 Gemini candidates / error 解析 SSE，不套用 Chat choices 解析器。

接入说明 / 错误

错误与限制

客户端应同时处理非 2xx 响应和流式 error 事件。

HTTP 状态原因处理
400 / 422参数、素材或类型错误查看 error.message 或 detail
401API Key 无效后台 API Key，不是 Google 凭据
404未实现接口 / 任务不存在核对路径、ID 和 Key 归属
409任务未完成 / 幂等键冲突查询任务或核对同键请求
410媒体缓存过期自行保存已下载文件
413 / 415素材超限 / 格式不支持缩小素材或换正确 Content-Type
503无可用账号 / 并发等待失败退避重试
500 / 502 / 504上游失败 / 超时任务先查状态，创建请求不盲目重发

错误示例

401 · JSON
{
  "error": {
    "message": "Invalid API key",
    "type": "authentication_error",
    "code": "invalid_api_key"
  }
}

部分请求边界可能返回 FastAPI detail。Gemini 错误为 {error:{code,message,status}}；SSE 开始后可能通过 error 报错，不能只看初始 HTTP 200。

仅 Videos 创建支持 Idempotency-Key。Chat、Images、Responses 没有相同幂等保障；关闭客户端自动重试，避免重复生成。
lay4flow · Swagger · OpenAPI JSON · 响应示例为结构示意，不代表真实生成结果。
